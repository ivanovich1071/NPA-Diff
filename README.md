# NPA.Diff — Сравнение редакций НПА

Веб-приложение для сравнения редакций нормативных правовых актов Республики Беларусь: показывает, что изменилось между старой и новой версией документа, формирует юридическое резюме изменений и позволяет задавать вопросы по обоим документам через встроенный чат на основе LLM.

## Возможности

- Загрузка документов тремя способами: файл (DOCX, PDF, TXT), вставка текста, ссылка на pravo.by, etalonline.by или nalog.gov.by.
- Автоматическое определение изменений между редакциями: добавления, удаления, замены и перемещённые фрагменты текста.
- Юридическое резюме изменений, сформированное LLM, с ранжированием по значимости.
- Чат по документам — можно задать вопрос по полному тексту старой или новой редакции, не только по найденным изменениям.
- История сравнений и постраничный просмотр различий.
- Интерфейс на русском и белорусском языках.

## Стек

- **Монорепозиторий**: pnpm workspaces, Node.js 24, TypeScript 5.9.
- **Frontend** (`artifacts/law-diff`): React + Vite.
- **Backend** (`artifacts/api-server`): Express 5, PostgreSQL + Drizzle ORM, Zod-валидация.
- **API-контракт**: OpenAPI-спецификация, кодогенерация клиента через Orval.
- **LLM**: доступ через Replit AI Integrations / OpenRouter.
- **Canvas/мокапы** (`artifacts/mockup-sandbox`): изолированный превью-сервер для прототипирования компонентов.

## Запуск

```bash
pnpm --filter @workspace/api-server run dev   # API-сервер
pnpm --filter @workspace/law-diff run dev      # веб-приложение
```

Подробности по структуре монорепозитория — в `replit.md`.

## Безопасность

Загрузка документов по ссылке ограничена доверенным списком доменов (pravo.by, etalonline.by, nalog.gov.by) с защитой от SSRF: проверка резолвинга DNS, запрет приватных IP-адресов, ограничение размера ответа и таймаута, повторная проверка при редиректах.
